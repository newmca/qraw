- `deep-nesting-dropped-element.html`: 200 nested `<b>` (`sanitizeHtml`). An element past the depth limit stayed as an empty leaf; its end tag closed an ancestor when the output was sanitized again, so the sanitizer was not idempotent. Fixed in `TreeBuilder::start` (`src/render/rich_text_html.cpp`): the element is dropped.
- `control-char-in-attribute.html`: `<font size="U+0017">` (`sanitizeHtml`). The attribute filter saw the control character, the serializer dropped it, so the output carried an empty `size` that the next pass removed (not idempotent). Fixed in `decodeEntities` (`src/render/rich_text_html.cpp`): characters XML cannot carry are dropped before any filter runs.
- `heading-in-paragraph-in-heading.html`: `<h1><p><h1>` (`sanitizeHtml`). A heading start tag closed an open heading only when it was the innermost element, before the open `<p>` was closed, so the second heading nested in the first and the next pass split them (not idempotent). Fixed in `TreeBuilder::impliedEndTags` (`src/render/rich_text_html.cpp`): the paragraph is closed first, as in the HTML spec.
